# Orbit Scientific Calculator

A playful, responsive scientific calculator built with HTML, CSS, and JavaScript. Open `index.html` in a modern browser to use it.

Features include standard arithmetic, brackets, percentages, powers, roots, trigonometric and inverse trigonometric functions, logarithms, factorials, constants, DEG/RAD mode, and memory controls. It also includes calculation history, light/dark themes, optional button sounds, keyboard shortcuts, and encouraging feedback.

Keyboard shortcuts: `Enter` calculates, `Escape` clears, and `Backspace` deletes.
